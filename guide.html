DOCUMENTATION / GETTING STARTED

Using CS Moments.

The desktop app processes video on your computer. This guide describes the main workflow and the checks to make before exporting or posting.

Before you start

  • Use a Windows computer with the project installed and its Python environment set up.
  • Install FFmpeg and FFprobe and make sure they are available on your system PATH.
  • Some AI-assisted features need an API key for the provider you choose. Read that provider's data and billing terms before enabling it.
  • TikTok posting is optional and requires your own TikTok for Developers app, configured credentials, and account authorization.

CS Moments is currently provided as a desktop project; a public installer or hosted video-editing service is not available from this website.

Generate a clip

  1. 01

    Start the desktop app

    In the project folder, run shorts-web.bat. Open http://127.0.0.1:8000 in your browser while the local server is running.

  2. 02

    Select a source recording

    Use Upload video(s), choose the generation mode and settings, then start processing.

  3. 03

    Review the output

    Inspect generated clips, titles, subtitles, framing, and audio. Edit settings or regenerate if needed; automated selection is not guaranteed to be accurate.

  4. 04

    Export or choose TikTok

    Keep the clip locally, or use the TikTok action if the account is connected and the required TikTok permissions are available.

Set up TikTok posting

  1. Configure Login Kit and Content Posting API in TikTok for Developers. The app uses the desktop redirect URI http://localhost:8000/api/tiktok/callback.
  2. Set the client key and client secret from the same Developer Portal environment used for the test (Sandbox or Production). The local launcher prompts for credentials when they are not set in the environment.
  3. Connect the TikTok account in the app. In the posting dialog, review the creator, caption, privacy, and interaction settings.
  4. Confirm only when you intend to send the selected video to TikTok. TikTok's unaudited-client restrictions and review status determine which privacy options are allowed.

Keep credentials private. Never put a client secret in a public website, source repository, screenshot, or support message.
