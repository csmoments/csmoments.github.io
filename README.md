# CS Moments public website

Static, dependency-free pages for GitHub Pages. Publish the contents of this folder from the repository root (`main` / `/(root)`) so the root-based links to `/privacy.html`, `/terms.html`, `/guide.html`, `/features.html`, `/support.html`, `/styles.css`, and `/assets/app-icon.png` resolve at `https://csmoments.github.io/`.

The same square `assets/app-icon.png` file is used in the page headers and as the browser icon. Upload this exact image as the app icon in TikTok for Developers. No installer or download URL is included because a public download location has not been provided.
